# 二分查找

## 一、核心思想

二分查找是一种高效的搜索算法，适用于有序数组。每次将搜索范围缩小一半，直到找到目标值或确定不存在。

**关键条件**：数组必须有序。

---

### 查找目标值是否存在

```cpp
int binarySearch(vector<int>& arr, int target) {
    int l = 0, r = arr.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;  // 防止溢出
        if (arr[mid] == target) {
            return mid;
        } else if (arr[mid] < target) {
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }
    return -1;
}
```

### 查找左边界

```cpp
int lowerBound(vector<int>& arr, int target) {

```

## 二、二分答案

### 核心思想
当答案满足单调性时，可以通过二分查找来确定最优解。

### 适用场景
- 最大化最小值问题
- 最小化最大值问题
- 满足条件的最大/最小值

### 代码

```cpp
bool check(int mid) {
    // 判断 mid 是否满足条件
    // 返回 true 或 false
}

int binaryAnswer(int left, int right) {
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (check(mid)) {
            right = mid;  // 满足条件，尝试更小的值
        } else {
            left = mid + 1;  // 不满足，需要更大的值
        }
    }
    return left;
}
```

### 示例：分割数组的最大值

```cpp
bool check(vector<int>& nums, int k, int mid) {
    int count = 1, sum = 0;
    for (int num : nums) {
        if (sum + num > mid) {
            count++;
            sum = num;
            if (count > k) return false;
        } else {
            sum += num;
        }
    }
    return true;
}

int splitArray(vector<int>& nums, int k) {
    int left = *max_element(nums.begin(), nums.end());
    int right = accumulate(nums.begin(), nums.end(), 0);
    
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (check(nums, k, mid)) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }
    return left;
}
```

## 四、例题

### 例题1：搜索旋转排序数组

```cpp
int search(vector<int>& nums, int target) {
    int l = 0, r = nums.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] == target) return mid;
        
        if (nums[l] <= nums[mid]) {
            if (target >= nums[l] && target < nums[mid]) {
                r = mid - 1;
            } else {
                l = mid + 1;
            }
        } else {
            if (target > nums[mid] && target <= nums[r]) {
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }
    }
    return -1;
}
```

### 例题2：寻找峰值

```cpp
int findPeakElement(vector<int>& nums) {
    int l = 0, r = nums.size() - 1;
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] < nums[mid + 1]) {
            l = mid + 1;
        } else {
            r = mid;
        }
    }
    return l;
}
```
