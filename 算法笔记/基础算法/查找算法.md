# 查找算法

## 一、顺序查找

### 算法思想
逐个遍历数组元素，直到找到目标值或遍历结束。

### 代码模板
```cpp
int sequentialSearch(vector<int>& arr, int target) {
    for (int i = 0; i < arr.size(); i++) {
        if (arr[i] == target) {
            return i;
        }
    }
    return -1;
}
```

### 复杂度
- 时间：O(n)
- 空间：O(1)

---

## 二、二分查找

### 算法思想
要求数组有序，每次将搜索范围缩小一半，直到找到目标值。

### 代码模板（查找目标值）
```cpp
int binarySearch(vector<int>& arr, int target) {
    int l = 0, r = arr.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (arr[mid] == target) {
            return mid;
        } else if (arr[mid] < target) {
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }
    return -1;
}
```

### 代码模板（查找第一个大于等于target）
```cpp
int lowerBound(vector<int>& arr, int target) {
    int l = 0, r = arr.size();
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (arr[mid] >= target) {
            r = mid;
        } else {
            l = mid + 1;
        }
    }
    return l;
}
```

### 代码模板（查找第一个大于target）
```cpp
int upperBound(vector<int>& arr, int target) {
    int l = 0, r = arr.size();
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (arr[mid] > target) {
            r = mid;
        } else {
            l = mid + 1;
        }
    }
    return l;
}
```

### 复杂度
- 时间：O(log n)
- 空间：O(1)

## 三、插值查找

### 算法思想
根据目标值估算可能位置，适用于均匀分布的有序数组。

### 代码模板
```cpp
int interpolationSearch(vector<int>& arr, int target) {
    int l = 0, r = arr.size() - 1;
    while (l <= r && target >= arr[l] && target <= arr[r]) {
        if (l == r) return (arr[l] == target) ? l : -1;
        
        int pos = l + (target - arr[l]) * (r - l) / (arr[r] - arr[l]);
        
        if (arr[pos] == target) return pos;
        else if (arr[pos] < target) l = pos + 1;
        else r = pos - 1;
    }
    return -1;
}
```

### 复杂度
- 时间：O(log log n)（均匀分布）
- 空间：O(1)

## 四、斐波那契查找

### 算法思想
利用斐波那契数列分割搜索区间，减少比较次数。

### 代码模板
```cpp
int fibonacciSearch(vector<int>& arr, int target) {
    int n = arr.size();
    int fib2 = 0, fib1 = 1, fib = fib1 + fib2;
    
    while (fib < n) {
        fib2 = fib1;
        fib1 = fib;
        fib = fib1 + fib2;
    }
    
    int offset = -1;
    while (fib > 1) {
        int i = min(offset + fib2, n - 1);
        if (arr[i] < target) {
            fib = fib1;
            fib1 = fib2;
            fib2 = fib - fib1;
            offset = i;
        } else if (arr[i] > target) {
            fib = fib2;
            fib1 = fib1 - fib2;
            fib2 = fib - fib1;
        } else {
            return i;
        }
    }
    
    if (fib1 && arr[offset + 1] == target) {
        return offset + 1;
    }
    return -1;
}
```

### 复杂度
- 时间：O(log n)
- 空间：O(1)

## 五、查找算法对比

| 算法 | 时间复杂度 | 空间复杂度 | 适用条件 | 特点 |
|------|-----------|-----------|---------|------|
| 顺序查找 | O(n) | O(1) | 无 | 简单，适用于无序或小规模 |
| 二分查找 | O(log n) | O(1) | 有序数组 | 高效，最常用 |
| 插值查找 | O(log log n) | O(1) | 均匀分布有序数组 | 分布均匀时最优 |
| 斐波那契查找 | O(log n) | O(1) | 有序数组 | 减少比较次数 |
