# 排序算法

## 一、冒泡排序

### 算法思想
重复遍历数组，比较相邻元素，将较大元素向后交换，直到整个数组有序。

### 代码
```cpp
void bubbleSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
            }
        }
    }
}
```

### 复杂度
- 时间：O(n²)
- 空间：O(1)

---

## 二、选择排序

### 算法思想
每次从未排序部分选出最小元素，放到已排序部分的末尾。

### 代码
```cpp
void selectionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) {
                minIdx = j;
            }
        }
        swap(arr[i], arr[minIdx]);
    }
}
```

### 复杂度
- 时间：O(n²)
- 空间：O(1)

---

## 三、插入排序

### 算法思想
将未排序元素逐个插入到已排序部分的正确位置。

### 代码
```cpp
void insertionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}
```

### 复杂度
- 时间：O(n²)（最好 O(n)）
- 空间：O(1)

---

## 四、快速排序

### 算法思想
选择基准元素，将数组分为两部分，左边小于基准，右边大于基准，递归排序。

### 代码
```cpp
int partition(vector<int>& arr, int l, int r) {
    int pivot = arr[r];
    int i = l - 1;
    for (int j = l; j < r; j++) {
        if (arr[j] <= pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[r]);
    return i + 1;
}

void quickSort(vector<int>& arr, int l, int r) {
    if (l < r) {
        int pi = partition(arr, l, r);
        quickSort(arr, l, pi - 1);
        quickSort(arr, pi + 1, r);
    }
}
```

### 复杂度
- 时间：O(n log n)（最坏 O(n²)）
- 空间：O(log n)

## 五、归并排序

### 算法思想
分治策略，将数组分成两半，分别排序后合并。

### 代码
```cpp
void merge(vector<int>& arr, int l, int mid, int r) {
    vector<int> left(arr.begin() + l, arr.begin() + mid + 1);
    vector<int> right(arr.begin() + mid + 1, arr.begin() + r + 1);
    
    int i = 0, j = 0, k = l;
    while (i < left.size() && j < right.size()) {
        if (left[i] <= right[j]) {
            arr[k++] = left[i++];
        } else {
            arr[k++] = right[j++];
        }
    }
    while (i < left.size()) arr[k++] = left[i++];
    while (j < right.size()) arr[k++] = right[j++];
}

void mergeSort(vector<int>& arr, int l, int r) {
    if (l < r) {
        int mid = l + (r - l) / 2;
        mergeSort(arr, l, mid);
        mergeSort(arr, mid + 1, r);
        merge(arr, l, mid, r);
    }
}
```

### 复杂度
- 时间：O(n log n)
- 空间：O(n)

## 六、堆排序

### 算法思想
利用堆的性质，每次取出堆顶元素，调整堆结构。

### 代码
```cpp
void heapify(vector<int>& arr, int n, int i) {
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;
    
    if (left < n && arr[left] > arr[largest]) largest = left;
    if (right < n && arr[right] > arr[largest]) largest = right;
    
    if (largest != i) {
        swap(arr[i], arr[largest]);
        heapify(arr, n, largest);
    }
}

void heapSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = n / 2 - 1; i >= 0; i--) heapify(arr, n, i);
    
    for (int i = n - 1; i > 0; i--) {
        swap(arr[0], arr[i]);
        heapify(arr, i, 0);
    }
}
```

### 复杂度
- 时间：O(n log n)
- 空间：O(1)

## 七、排序算法对比

| 算法 | 时间复杂度 | 空间复杂度 | 特点 |
|------|-----------|-----------|------|
| 冒泡排序 | O(n²) | O(1) | 简单，效率低 |
| 选择排序 | O(n²) | O(1) |  交换次数少 |
| 插入排序 | O(n²) | O(1) |  适合小规模或基本有序 |
| 快速排序 | O(n log n) | O(log n) | 平均性能最好 |
| 归并排序 | O(n log n) | O(n) | 适合外排序 |
| 堆排序 | O(n log n) | O(1) | 空间效率高 |
