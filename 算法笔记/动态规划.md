# 动态规划

## 一、核心思想

动态规划是一种将复杂问题分解为子问题求解的方法，通过保存子问题的解避免重复计算。

**关键要素**：
- 状态定义
- 状态转移方程
- 初始状态
- 答案位置

## 二、线性DP

### 例题1：最长递增子序列

```cpp
int lengthOfLIS(vector<int>& nums) {
    int n = nums.size();
    vector<int> dp(n, 1);
    int max_len = 1;
    
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        max_len = max(max_len, dp[i]);
    }
    return max_len;
}
```

### 例题2：最大子数组和

```cpp
int maxSubArray(vector<int>& nums) {
    int n = nums.size();
    vector<int> dp(n);
    dp[0] = nums[0];
    int max_sum = dp[0];
    
    for (int i = 1; i < n; i++) {
        dp[i] = max(nums[i], dp[i - 1] + nums[i]);
        max_sum = max(max_sum, dp[i]);
    }
    return max_sum;
}
```

## 三、区间DP

### 核心思想
先计算小区间的解，再由小区间合并得到大区间的解。

### 例题：最长回文子串

```cpp
string longestPalindrome(string s) {
    int n = s.size();
    vector<vector<bool>> dp(n, vector<bool>(n, false));
    int max_len = 1, start = 0;
    
    for (int i = n - 1; i >= 0; i--) {
        for (int j = i; j < n; j++) {
            if (j - i < 2) {
                dp[i][j] = (s[i] == s[j]);
            } else {
                dp[i][j] = (s[i] == s[j] && dp[i + 1][j - 1]);
            }
            
            if (dp[i][j] && j - i + 1 > max_len) {
                max_len = j - i + 1;
                start = i;
            }
        }
    }
    return s.substr(start, max_len);
}
```

## 四、背包问题

### 1. 0-1背包

```cpp
int knapsack01(vector<int>& weights, vector<int>& values, int capacity) {
    int n = weights.size();
    vector<int> dp(capacity + 1, 0);
    
    for (int i = 0; i < n; i++) {
        for (int j = capacity; j >= weights[i]; j--) {
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i]);
        }
    }
    return dp[capacity];
}
```

### 2. 完全背包

```cpp
int knapsackComplete(vector<int>& weights, vector<int>& values, int capacity) {
    int n = weights.size();
    vector<int> dp(capacity + 1, 0);
    
    for (int i = 0; i < n; i++) {
        for (int j = weights[i]; j <= capacity; j++) {
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i]);
        }
    }
    return dp[capacity];
}
```

### 3. 多重背包

```cpp
int knapsackMultiple(vector<int>& weights, vector<int>& values, vector<int>& counts, int capacity) {
    int n = weights.size();
    vector<int> dp(capacity + 1, 0);
    
    for (int i = 0; i < n; i++) {
        for (int j = capacity; j >= weights[i]; j--) {
            for (int k = 1; k <= counts[i] && j >= k * weights[i]; k++) {
                dp[j] = max(dp[j], dp[j - k * weights[i]] + k * values[i]);
            }
        }
    }
    return dp[capacity];
}
```

## 五、状态压缩DP

### 例题：旅行商问题

```cpp
int tsp(vector<vector<int>>& dist) {
    int n = dist.size();
    int full_mask = (1 << n) - 1;
    vector<vector<int>> dp(n, vector<int>(1 << n, INT_MAX));
    
    for (int i = 0; i < n; i++) dp[i][1 << i] = 0;
    
    for (int mask = 1; mask <= full_mask; mask++) {
        for (int i = 0; i < n; i++) {
            if (!(mask & (1 << i))) continue;
            for (int j = 0; j < n; j++) {
                if (!(mask & (1 << j))) continue;
                dp[i][mask] = min(dp[i][mask], dp[j][mask ^ (1 << i)] + dist[j][i]);
            }
        }
    }
    
    int ans = INT_MAX;
    for (int i = 0; i < n; i++) {
        ans = min(ans, dp[i][full_mask]);
    }
    return ans;
}
```

## 六、树形DP

### 例题：二叉树中的最大路径和

```cpp
int max_sum = INT_MIN;

int maxGain(TreeNode* node) {
    if (!node) return 0;
    
    int left_gain = max(maxGain(node->left), 0);
    int right_gain = max(maxGain(node->right), 0);
    
    int current_sum = node->val + left_gain + right_gain;
    max_sum = max(max_sum, current_sum);
    
    return node->val + max(left_gain, right_gain);
}

int maxPathSum(TreeNode* root) {
    maxGain(root);
    return max_sum;
}
```

## 七、DP解题步骤

1. **确定状态**：定义 dp[i] 或 dp[i][j] 表示什么
2. **状态转移**：找出 dp[i] 与之前状态的关系
3. **初始状态**：确定边界条件
4. **答案位置**：确定最终答案在哪里

---

## 八、常见DP类型

| 类型 | 特点 | 典型问题 |
|------|------|---------|
| 线性DP | 一维状态转移 | LIS、最大子数组和 |
| 区间DP | 区间合并 | 最长回文子串、石子合并 |
| 背包DP | 容量限制选择 | 0-1背包、完全背包 |
| 状态压缩 | 二进制表示状态 | 旅行商问题 |
| 树形DP | 在树上进行DP | 树的直径、最大路径和 |
