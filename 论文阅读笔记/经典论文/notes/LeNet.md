## 🎯 研究背景

### 问题定义

手写数字和字符识别是模式识别的经典问题，传统方法依赖手工特征提取。

### 现有挑战

1. **特征工程**: 需要人工设计特征
2. **泛化能力**: 对新字体、书写风格适应性差
3. **计算复杂度**: 传统方法计算开销大
4. **准确率**: 识别准确率有待提升

### 研究动机

- 神经网络具有自动学习特征的能力
- 卷积操作适合图像处理
- 反向传播算法可以训练多层网络

---

## 💡 主要贡献

1. 提出卷积神经网络（CNN）的基本架构
2. 引入反向传播算法训练卷积网络
3. 在手写数字识别上取得突破性成果
4. 奠定现代深度学习的基础

---

## 🔧 方法概述

### 网络架构

```
输入 (32×32) → C1 (28×28) → S2 (14×14) → C3 (10×10) → S4 (5×5) → C5 → F6 → 输出
```

### LeNet-5 详细结构

| 层 | 类型 | 输入尺寸 | 输出尺寸 | 参数量 |
|----|------|----------|----------|--------|
| Input | 输入层 | - | 32×32×1 | 0 |
| C1 | 卷积层 | 32×32×1 | 28×28×6 | 156 |
| S2 | 池化层 | 28×28×6 | 14×14×6 | 12 |
| C3 | 卷积层 | 14×14×6 | 10×10×16 | 1,516 |
| S4 | 池化层 | 10×10×16 | 5×5×16 | 32 |
| C5 | 卷积层 | 5×5×16 | 1×1×120 | 48,120 |
| F6 | 全连接层 | 120 | 84 | 10,164 |
| Output | 输出层 | 84 | 10 | 850 |

**总参数量**: 约 60,000

### 核心组件

1. **卷积层**: 局部感受野，权值共享
2. **池化层**: 下采样，降低分辨率
3. **全连接层**: 特征组合，分类输出
4. **激活函数**: Sigmoid / Tanh

### 关键技术

- **局部感受野**: 每个神经元只连接局部区域
- **权值共享**: 同一特征图使用相同卷积核
- **下采样**: 池化操作降低空间分辨率
- **反向传播**: 梯度下降优化网络参数

---

## 📊 实验结果

### 数据集

- MNIST 手写数字数据集
- 60,000 训练样本，10,000 测试样本
- 32×32 灰度图像

### 性能指标

- 错误率: 0.95% (MNIST)
- 识别速度: 快
- 模型大小: 约 60K 参数

### 对比实验

| 方法 | 错误率 |
|------|--------|
| 线性分类器 | 8.4% |
| K-近邻 | 3.1% |
| SVM | 1.4% |
| LeNet-5 | 0.95% |

## 🎓 学习要点

### 核心思想

1. **端到端学习**: 从原始像素到分类结果
2. **层次特征**: 逐层提取抽象特征
3. **局部连接**: 减少参数，提高效率
4. **权值共享**: 平移不变性

### 关键创新

- 卷积神经网络架构
- 反向传播训练算法
- 端到端学习范式

### 影响深远

- 开创了深度学习时代
- 为 AlexNet、VGG、ResNet 奠定基础
- 卷积操作成为视觉任务的标准组件

---

## 🤔 思考与问题

### 优点

1. 自动学习特征，无需人工设计
2. 平移不变性
3. 参数量相对较少
4. 训练效率高

### 局限性

1. 网络深度较浅
2. 使用 Sigmoid 激活，存在梯度消失
3. 缺乏现代技术（如 BatchNorm、ReLU）
4. 数据量较小时容易过拟合

### 历史意义

- 深度学习的奠基之作
- 证明了神经网络在模式识别上的有效性
- 开启了卷积神经网络的研究热潮
